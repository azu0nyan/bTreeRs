1//! Capability traits a context type `D` can opt into.
2//!
3//! Some nodes need more from the context than the bare ability to be ticked —
4//! a timer node needs to know how much time elapsed, a randomized node needs a
5//! source of randomness. Rather than baking an engine clock or RNG into the
6//! library (which would break its dependency-free, engine-agnostic promise),
7//! those needs are expressed as small traits that the context implements:
8//!
9//! * [`HasDelta`] — the context can report the elapsed time of the current
10//!   tick. Required by the timing nodes ([`Wait`](crate::Wait),
11//!   [`Delay`](crate::Delay), [`Cooldown`](crate::Cooldown),
12//!   [`TimeLimit`](crate::TimeLimit), [`RandomWait`](crate::RandomWait)).
13//! * [`HasRng`] — the context can produce uniform random numbers. Required by
14//!   the randomized nodes ([`RandomSequence`](crate::RandomSequence),
15//!   [`RandomSelector`](crate::RandomSelector),
16//!   [`ProbabilitySelector`](crate::ProbabilitySelector),
17//!   [`Probability`](crate::Probability), [`RandomWait`](crate::RandomWait)).
18//! * [`HasNavAgent`] — the context's agent can compute a navigation path to a
19//!   target. Required by [`SetDestination`](crate::SetDestination).
20//! * [`FollowPath`] — the context's agent can move along a computed path.
21//!   Required by [`GoTo`](crate::GoTo).
22//!
23//! A node that needs a capability simply bounds the impl, e.g.
24//! `impl<D: HasDelta> BehaviorNode<D> for Wait`, so it is only usable on
25//! contexts that provide it. Nodes that need nothing extra stay generic over
26//! any `D`.
27

29mod has_delta;
30mod has_nav_agent;
31mod has_rng;
