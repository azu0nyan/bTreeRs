Expand description

A context that can produce uniform random numbers.

The only required method is next_f64, a uniform draw from [0.0, 1.0); the convenience methods are derived from it. Keeping the source of randomness in the context (rather than a global or a library dependency) means trees stay deterministic and unit-testable: a test can supply a context whose draws are a fixed queue, while a game supplies one backed by the engine RNG.

use btree::prelude::*;

struct Det { values: Vec<f64>, at: usize }
impl HasRng for Det {
    fn next_f64(&mut self) -> f64 {
        let v = self.values[self.at % self.values.len()];
        self.at += 1;
        v
    }
}
